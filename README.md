# PixelWallet

PixelWallet est une solution de paiement sécurisée destinée aux mineurs pour leurs achats de jeux vidéo. L'application permet aux parents de créer et gérer des cartes virtuelles pour leurs enfants avec des contrôles parentaux avancés.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Hamagistral/PixelWallet.git
    ```
2. Navigate to the project directory:
    ```bash
    cd PixelWallet
    ```
3. Install the required dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the application:
    ```bash
    npm run dev
    ```
2. Open your browser and navigate to `http://localhost:3000`.
